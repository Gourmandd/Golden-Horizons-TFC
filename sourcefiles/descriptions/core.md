
# On Ancient Ground - Core

This mod adds essential content for the On Ancient Ground modpack. Which is a 1.21 modpack based on TerraFirmaCraft (TFC).

This mod is open source with the hope that its code can help others make mods, especially for addons or modpacks centered around TerraFirmaCraft since this mod registers custom rocks, ores, wood types, metals, crops, and mold items.

# Note
Keep in mind that no datapack or resource pack assets are in the mod as of now, all of these assets are in the modpack the mod is written for. Many of these are subject to move into the jar file itself.
